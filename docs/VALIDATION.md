# Validation report

**TONIC has been installed and runs on an M-VAVE FM-1.** The checks below were established in software, for every
release: TONIC's engine tests, the host simulator, the browser emulator (the same code in WebAssembly) and fm1-emu,
an instruction-level emulator of the FM-1 that runs the real firmware file. What each environment is and is not: `docs/TEST_ENVIRONMENT.md`.
Status as of 2026-10-25, firmware 0.12.1 (`release/tonic-0.12.1.fwsc`, SHA-256 `a8f3dbaa…`; 0.1 to 0.12 stay in `release/`; 0.12.1: a page a drum pad, ARP > SCALE its own page, the MENV envelope drawn; 0.12: per-pad drum controls and pan, the insert effect, the modulation envelope, the sound's scale and chords by degrees, LEN and SCALE always per track; 0.11: twelve voices; 0.10.1: the performance audit, the same sound with 30 KB less RAM and 16 points less CPU on the FM benchmark; 0.10: volume shaping and the PUMP page (a kit source's pad, attack, a track kept out); 0.9.2: the functional audit's 31 fixes (euclid, sequencer, saving, sound); 0.9.1: the UI audit's quick fixes; 0.9 adds ten drum models and 22 modulation destinations; 0.8 extends the chords and EUCLID; 0.7 adds the momentary effects; 0.6.1 picks a kit's pad from the grid and with OCT; 0.6 adds euclid, arp chords, the compressor, FOLD / RING and four drum models; 0.5.1 moved the kit's ENGINE to K4, 0.5.2 is 0.5.1 optimized: the same sound sample for sample, less CPU and RAM), fm1-base `6c0b47e`,

## 3. Fidelity to the Digitone

Checked against the OS: the parameter mappings that `docs/RESEARCH.md` §3 marks VERIFIED are implemented from the
measured tables and formulas (as sparse curves, `core/curves.h`; `tools/gen_curves.py` prints each curve's largest error against its table: 0.2–0.5 %
for detune and level, 1–2 % for the operator envelope times) and the amp decay is checked end to end above. Everything marked INFERRED or APPROX there,
the effects in particular, is TONIC's own and has not been compared with the instrument. Two differences are
structural: TONIC runs at 44.1 kHz without the OS's 96 kHz operators (more aliasing at high ratios and index), and
its LP2 and LP4 filters reproduce the OS's constants and measured responses with their own difference equations.

## 4. How to reproduce

`docs/BUILDING.md` §Tests runs all of it: the engine tests, the four host scripts, the browser emulator test, the
fm1-emu tests and the sound report.
